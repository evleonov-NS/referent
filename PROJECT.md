# Референт — AI-помощник для иностранных статей и писем

> Актуальный статус разработки: [STATUS.md](./STATUS.md)

**Референт** — это учебное приложение, созданное на фреймворке **Next.js**, которое помогает быстро разбирать статьи и письма на иностранном языке.

Пользователь может указать ссылку на статью, вставить скопированный текст статьи или вставить текст письма. После этого приложение анализирует материал с помощью искусственного интеллекта и предлагает удобные варианты обработки информации.

## Технические требования

* фреймворк **Next.js**;
* интерфейс на **Tailwind CSS** (форма, кнопки, показ результата);
* шаблон Next.js как основа проекта.

## Возможности для статей

* кратко объяснить, о чём статья;
* выделить основные тезисы;
* сделать подробный перевод на русский язык;
* вывести результат в отдельное поле;
* скопировать переведённый текст.

## Возможности для писем

Пользователь вставляет текст письма на иностранном языке.

Приложение предлагает:

* подробный перевод письма на русский язык;
* подготовку ответа на письмо;
* ответ на языке оригинала;
* ответ на русском языке;
* возможность скопировать английский вариант ответа;
* возможность скопировать русский вариант ответа.

## Кнопки для режима писем

* «Перевести письмо»
* «Подготовить ответ»
* «Скопировать ответ на языке оригинала»
* «Скопировать ответ на русском»

## Результат

Пользователь быстро понимает содержание иностранной статьи или письма, получает перевод и при необходимости готовый вариант ответа на двух языках.
