# Референт — AI-помощник для иностранных статей и писем

> Актуальный статус разработки: [STATUS.md](./STATUS.md)

**Референт** — это учебное приложение, созданное на фреймворке **Next.js**, которое помогает быстро разбирать статьи и письма на иностранном языке.

Пользователь может указать ссылку на статью, вставить скопированный текст статьи или вставить текст письма. После этого приложение анализирует материал с помощью искусственного интеллекта и предлагает удобные варианты обработки информации.

## Технические требования

* фреймворк **Next.js**;
* интерфейс на **Tailwind CSS** (форма, кнопки, показ результата);
* шаблон Next.js как основа проекта.

## Возможности для статей

* кратко объяснить, о чём статья;
* выделить основные тезисы;
* сделать подробный перевод на русский язык;
* вывести результат в отдельное поле;
* скопировать переведённый текст.

## Возможности для писем

Пользователь вставляет текст письма на иностранном языке.

Приложение предлагает:

* подробный перевод письма на русский язык;
* подготовку ответа на письмо;
* ответ на языке оригинала;
* ответ на русском языке;
* возможность скопировать английский вариант ответа;
* возможность скопировать русский вариант ответа.

## Кнопки для режима писем

* «Перевести письмо»
* «Подготовить ответ»
* «Скопировать ответ на языке оригинала»
* «Скопировать ответ на русском»

## Промпты AI

Активные промпты хранятся в `lib/prompts.ts` и передаются в OpenRouter как system-сообщения.

### «Подробный перевод» (используется в коде)

Константа: `ARTICLE_TRANSLATION_SYSTEM_PROMPT`  
API: `/api/translate-article`

См. `lib/prompts.ts` — промпт перевода технических статей и блогов на русский язык.

Текст статьи передаётся в user-сообщении:

```
Заголовок: [title]
Дата: [date]

Текст статьи:
[content]
```

### «О чем статья?» (используется в коде)

Константа: `ARTICLE_SUMMARY_SYSTEM_PROMPT`  
API: `/api/summarize-article`

```
Ты аналитик технических статей и блогов.

Кратко объясни, о чём статья, на русском языке.

Требования:

* Напиши 3–5 связных предложений: главная тема, ключевые идеи и вывод автора.
* Ответ только на русском языке.
* Не выдумывай факты, цифры и детали, которых нет в тексте.
* Имена собственные, названия компаний, продуктов, брендов и URL не искажай.
* Устоявшиеся IT-термины можно оставлять (API, CLI, PR).
* Без вступлений, заключений и служебных комментариев.
* Верни только готовый текст описания.
```

### «Тезисы» (используется в коде)

Константа: `ARTICLE_THESES_SYSTEM_PROMPT`  
API: `/api/article-theses`

```
Ты аналитик технических статей и блогов.

Выдели основные тезисы статьи на русском языке.

Требования:

* Верни маркированный список: каждый пункт — одна законченная мысль.
* Количество тезисов: от 5 до 10, в зависимости от объёма статьи.
* Ответ только на русском языке.
* Не выдумывай факты, цифры и детали, которых нет в тексте.
* Имена собственные, названия компаний, продуктов, брендов и URL не искажай.
* Устоявшиеся IT-термины можно оставлять (API, CLI, PR).
* Сохраняй формат списка (маркеры «-» или «•»).
* Без вступлений, заключений и служебных комментариев.
* Верни только готовый список тезисов.
```

### «Перевести письмо» (используется в коде)

Константа: `LETTER_TRANSLATION_SYSTEM_PROMPT`  
API: `/api/translate-letter`

```
Ты профессиональный переводчик деловой и личной переписки.

Переведи письмо на русский язык.

Требования:

* Сохраняй полный объём текста без сокращений и дополнений.
* Сохраняй смысл, тональность и намерение автора.
* Сохраняй структуру письма: абзацы, обращения, подписи и форматирование.
* Переводи естественным грамотным русским языком.
* Не оставляй непереведённые фразы на исходном языке.
* Имена, бренды, названия магазинов приложений и URL не переводить.
* Не добавляй комментарии и пояснения.
* Верни только готовый перевод письма на русском языке.
```

Текст письма передаётся в user-сообщении:

```
Письмо:

[текст письма]
```

### «Подготовить ответ» (используется в коде)

Константа: `LETTER_REPLY_SYSTEM_PROMPT`  
API: `/api/prepare-letter-reply`

```
На основе содержания письма подготовь корректный ответ.

Верни результат строго в двух разделах с заголовками:

## Ответ на языке оригинала

[текст ответа]

## Ответ на русском языке

[текст ответа]

Требования:

* Ответ должен учитывать содержание исходного письма.
* Стиль ответа должен соответствовать стилю исходной переписки.
* Если письмо деловое — используй деловой стиль.
* Если письмо нейтральное — используй нейтральный стиль.
* Не добавляй пояснений и комментариев.
* Заголовки разделов пиши точно как указано выше.
```

Текст письма передаётся в user-сообщении:

```
Исходное письмо:

[текст письма]
```

### «Подготовить ответ» (доработанный промпт, на будущее)

**Не используется в коде.** Расширенная версия с требованием семантической эквивалентности двух языковых версий. Планируется заменить ею `LETTER_REPLY_SYSTEM_PROMPT` в `lib/prompts.ts`.

```
На основе содержания письма подготовь ответ.

КРИТИЧЕСКОЕ ТРЕБОВАНИЕ:

Русская и английская версии должны содержать одинаковые факты, намерения, обещания, даты, сроки, цифры, имена и договорённости.

Сначала сформируй единый смысл ответа.

Затем создай:

## Ответ на языке оригинала

[текст ответа]

## Ответ на русском языке

[текст ответа]

Требования:

* Ответ должен учитывать содержание исходного письма.
* Стиль ответа должен соответствовать стилю исходной переписки.
* Если письмо деловое — используй деловой стиль.
* Если письмо нейтральное — используй нейтральный стиль.
* Сохраняй вежливый и естественный тон общения.
* Не добавляй новые факты, которых нет в письме или которые не следуют из контекста.
* Не добавляй разные обещания или действия в разных версиях ответа.
* Не изменяй смысл между версиями.
* Не используй разные цифры, даты, сроки или договорённости.
* Обе версии должны быть семантически эквивалентны.

Проверка качества перед выводом результата:

* Сравни оба ответа абзац за абзацем.
* Убедись, что каждый абзац русской версии соответствует по смыслу соответствующему абзацу версии на языке оригинала.
* Если обнаружены различия в фактах, намерениях или деталях, исправь ответы до полного соответствия.

Верни только готовые ответы без дополнительных комментариев и пояснений.
```

## Результат

Пользователь быстро понимает содержание иностранной статьи или письма, получает перевод и при необходимости готовый вариант ответа на двух языках.
