# Референт

AI-помощник для анализа иностранных статей и писем.

Проект разрабатывается на Next.js и предназначен для быстрого понимания содержания иностранных материалов без необходимости полного чтения или самостоятельного перевода.

## Основные возможности

- анализ статей по URL;
- анализ вставленного текста;
- краткое описание содержания статьи;
- выделение тезисов;
- подробный перевод на русский язык;
- перевод иностранных писем;
- генерация ответа на письмо;
- подготовка ответа на языке оригинала и на русском языке;
- копирование результатов в буфер обмена.
